# Mash Runner
*Mash Runner* is a fast-paced 2D racing game developed using **Unreal Engine**, created as part of [*The Ultimate Unreal Engine 2D Game Development Course*](https://www.udemy.com/course/unreal-2d-course/) on **Udemy**, taught by **Cobra Code**.

## About the Game
In *Mash Runner*, you compete in a high-speed foot race against an NPC opponent. Your character gains speed by **alternately mashing two buttons** as fast as possible - the quicker you press, the faster you run!

### Gameplay Mechanics
- Two characters: one controlled by the **player**, the other by the **computer**.
- Rapidly **alternate pressing two keys** to gain speed.
- Outrun your opponent to win the race.
- Includes a finish line, speed-based movement, and simple AI competition.

This project is designed to learn using sprite sheets, flipbook animations, triggering an event on certain flipbook frame and adjust flipbook playrate. For this project I implement an AI Controller and create a blueprint for dynamically creating a stage (track length).

## Purpose

This is the **second project** in a series of small games built as hands-on practice for learning 2D game development in Unreal Engine through the Udemy course by Cobra Code.

## Built With

- [Unreal Engine 5.2](https://www.unrealengine.com/)
